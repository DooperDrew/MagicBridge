# 04 — UX

> Status: **DRAFT**

## Tray icon (always present)
- Icon shows state: normal / paused / keyboard disconnected.
- Tooltip: `MagicBridge — Bluetooth — Battery 78% — Media keys first`.
- Right-click menu:
  - ✅ Enabled (toggle, same as the pause hotkey)
  - Top row: ◉ Media keys first / ○ F-keys first
  - Open settings…
  - Start with Windows ✓
  - Quit
- Double-click opens settings.

## Settings window (`magicbridge-settings.exe`)
Small, fixed-size window (about 900×520). Sections are shown as tabs or a left sidebar:

1. **Keyboard** (main view)
   - Visual A1843 keyboard drawn to scale, with the full layout including the numpad and F13–F19.
   - Layer switch: **Normal** | **Fn**.
   - Remapped keys are highlighted. Clicking a key opens a side panel:
     *"Original: F13 → Action: [Key ▾] [Print Screen ▾]"* plus a "Reset" button.
   - "Press a key to select it" mode as an alternative to clicking.
   - Presets dropdown: *Windows layout*, *Mac layout*, *Reset all*.
2. **Top row & Fn**: Media-first / F-keys-first; toggle hotkey; Fn fallback key.
3. **Battery**: current level, notification threshold, poll interval.
4. **General**: UI language (English / Italiano), physical layout (ANSI / ISO), autostart,
   pause hotkey, game mode + process list, debug logging, import/export config.
5. **About**: version, link to project, status (agent running, transport, device detected).

## Behaviour
- Every change is saved and applied immediately. No "Apply" button.
- If the agent isn't running, the GUI shows a banner with a "Start agent" button.
- Closing the window exits the settings process completely.
