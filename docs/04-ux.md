# 04 — UX

> Status: **APPROVED / PRODUCTION UX (v0.2.0)**  
> Application: **MagicBridge Settings** (`magicbridge-settings.exe`)

## Tray icon (always present)
- Icon shows state: normal / paused / keyboard disconnected.
- Tooltip: `MagicBridge — Bluetooth — Battery 78% — Profile: Default (IT) — Media keys first`.
- Right-click menu:
  - ✅ Enabled (toggle, same as the pause hotkey)
  - Profile: ◉ Default (IT) / ○ English (US) / ○ Gaming …
  - Top row: ◉ Media keys first / ○ F-keys first
  - Open settings…
  - Start with Windows ✓
  - Quit
- Double-click opens settings.

## Settings window (`magicbridge-settings.exe`)
Responsive window with fluid visual scaling and adaptive navigation layout:
- **Expanded Mode (&ge; 850px):** Full-width navigation tab bar with descriptive labels and side-by-side key inspector.
- **Compact Mode (< 850px):** Icon-only navigation rail with tooltips, dynamic vertical stacking, and clamped key dimensions (`key_size = clamp(available_width / 24.5, 20.0, 42.0)`).

### Navigation Tabs:
1. **⌨️ Keyboard** (main layout view)
   - **Profile bar** at top: active profile dropdown + *New*, *Duplicate*, *Rename*, *Delete* buttons, and **Language/Physical Layout** selector (`ISO Italian`, `ANSI US`, `ISO UK`, `ISO German`, `ISO French`, `Custom`).
   - Visual A1843 keyboard drawn to scale with numpad and F13–F19.
   - Layer switch: **Normal** | **Fn**.
   - Remapped keys highlighted with dedicated colors; clicking opens side panel with remap action choices.
   - Presets dropdown: *Windows layout*, *Mac layout*, *Reset all*.
2. **🪄 Setup Wizard**: 6-step guided first-run onboarding (hardware detection, layout, modifier presets, Fn key choice, autostart, interactive test box).
3. **🧪 Hardware QA**: 109-key interactive diagnostic test matrix with live modifier state listeners and timestamped QA report export.
4. **🔉 Top Row & Fn**: Media-first / F-keys-first mode; toggle hotkey; Fn fallback key choice.
5. **🔋 Battery**: Current level, charging status, notification threshold, poll interval.
6. **⚙️ General**: UI language (English / Italiano), autostart, pause hotkey, game mode process list, debug logging, import/export config.
7. **🤖 Architecture**: Interactive didactic architecture diagrams, multi-agent methodology breakdown, and GitHub links.
8. **ℹ️ About**: Version, project links, agent running status, transport, and device detection.

## Behaviour
- Every change is saved and applied immediately. No "Apply" button.
- If the agent isn't running, the GUI shows a banner with a "Start agent" button.
- Closing the window exits the settings process completely. Zero idle RAM.
